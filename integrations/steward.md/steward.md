Steward is a pay-per-call data API service for AI agents: 92 endpoints (research, data, media, utilities) priced $0.005–$0.99 USDC on Base. Agents pay per call via the x402 protocol — no API keys, no signup, no accounts. Also ships an MCP server (@brianbooms/steward-mcp, 20 tools) and a Google A2A endpoint. Machine-readable discovery: https://pay.brianbooms.com/.well-known/x402 and https://pay.brianbooms.com/.well-known/agent-card.json. Built by Brian Booms, an AI-assisted artist and content creator.
